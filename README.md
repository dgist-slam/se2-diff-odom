# SE(2) Differential Drive Odometry Simulator

Interactive visualization of SE(2) pose composition for differential drive robots.

**Live Demo:** https://dgist-slam.github.io/se2-diff-odom/

## Features

- Real-time SE(2) pose composition visualization
- Adjustable wheel radius (r) and half-axle length (l)
- Keyboard-driven robot control mode
- Letter-tracing presets (SLAM, DGIST, ROBOT)
- Step-by-step animation with scrubbing
- Hover tooltips showing pose at each step

## Development

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` automatically deploy to GitHub Pages via GitHub Actions.
